# YouTube CLI Downloader

![yt-dlp](https://img.shields.io/badge/yt--dlp-FF0000?logo=youtube&logoColor=white)

A minimal **Python** CLI tool to download audio from **YouTube** in maximum quality.

## Installation

1. Clone or download this repository.
2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

```bash
python download.py [url] [output_directory]
```
